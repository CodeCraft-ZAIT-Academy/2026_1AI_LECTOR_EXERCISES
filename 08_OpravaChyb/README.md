# Opravovanie chýb – 27 úloh

Každá úloha je samostatný projekt (`Uloha01` … `Uloha27`) a každý obsahuje program s chybou (alebo chybami).

## Ako na to
1. Otvor `OpravaChyb.sln` vo Visual Studiu.
2. V *Solution Explorer* klikni pravým tlačidlom na projekt, ktorý chceš riešiť → **Set as Startup Project** (názov sa zvýrazní tučným písmom).
3. Spusti klávesom **F5** (alebo Ctrl+F5). Visual Studio zostaví **iba** tento projekt.
4. Prečítaj chybové hlásenie v okne *Error List*, nájdi chybu a oprav ju.
5. Keď úloha funguje, vyber ďalší projekt.

## Pozor
- **Nepoužívaj Build Solution (Ctrl+Shift+B)** – zostavil by všetkých 27 projektov a v Error List by boli chyby zo všetkých úloh. Používaj F5, alebo pravý klik na projekt → *Build*.
- Chyba nemusí byť len červená. Niekedy program beží, ale počíta zle – skontroluj aj výsledok.
- Ak je v prvých riadkoch komentár s *Správnym výstupom*, zisti, prečo sa výstup od neho líši.
